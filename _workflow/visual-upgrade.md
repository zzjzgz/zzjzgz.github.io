# S2 · 视觉升级记录（Apple Craft 令牌移植等价路径）

裁决依据见 `gate-a.md`：唯一视觉真源是 Apple Craft，不引入第二套主题。以下为实际执行的核验与补齐，不是虚构的 before/after 版本。

| 项 | 规格要求 | 检查发现 | 处理 | 结果 |
|---|---|---|---|---|
| 地面色 | 冷灰白 `#f5f5f7`，禁止暖米色 | 符合 | 保留 | PASS |
| 令牌覆盖 | 颜色 / 字体 / 圆角 / 阴影 / 间距 / 动效六类全变量化 | `:root` 共 46 个自定义属性 | 由 `extract_tokens.py` 从 `:root` 实解析生成 `tokens.json` | 一致率 14/14（100%） |

## 被否决的方案
1. **四张截图并排卡片墙**：碎片化，且首屏过载；改为分段控件 + 单容器 crossfade。
2. **给三个「不」各配彩色图标与左边框**：违反单一强调色与「克制即奢侈」；改为编号 + 发丝线。
3. **入场 fade-up keyframes**：异步渲染可能卡在 opacity 0，且营销页不需要；改为静态呈现 + 交互驱动动效。
4. **再移植 `hifi-prototype` 主题**：会与 Apple Craft 令牌互相覆盖；按 Gate A 裁决否决。

## 动效预算
静态 UI ≤ 280ms；唯一 420ms 档位保留给全表面覆盖层（本页未使用）。按频率门控：导航滚动反馈属于高频，只做 hairline 渐入，不做位移动画。
