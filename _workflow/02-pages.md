# 02 · P0 区段清单与定义（S1）

落地页为**单页长滚动**，这里的「页面」= 有独立主任务的锚点区段（`data-pid`），共 5 个 P0 区段。另有 3 个支撑性 section（数据属于你 / 规格 / FAQ），不单独计页。

| Page | 名称 | 角色 | 主任务 | 入口 | 出口 |
|---|---|---|---|---|---|
| P1 | 首页 | 第一印象 + 主张 | 30 秒理解产品并看到真实界面 | 外部链接 / 域名根 | 三个不 / 下载 |
| P2 | 为什么 | 信任建立 | 确认不上传、不评判、不收费 | P1 滚动 / 导航 | 界面 |
| P3 | 界面 | 功能确认 | 切换四个视图，判断够不够用 | P2 / 导航 | 隐私 |
| P4 | 隐私 | 顾虑消除 | 核对记录边界与数据可搬走 | P3 / 导航 | 下载 |
| P5 | 下载 | 转化 | 到达发布仓并选择产物 | 导航 CTA / P4 / FAQ | 外部 Gitee 目录 |

## 每页 12 项定义

### P1 · 首页（`data-pid="p1-home"`）
1. 锚点：`#top`
2. 主任务：理解主张 + 看到真实界面
3. 主视觉：1440×900「今天」视图截图，外层圆角 + 双层阴影
4. 关键组件：eyebrow / H1 / lede / 双按钮 / 版本事实行 / source badge
5. 主 CTA：`下载 Windows 版`（页内锚点至 P5）
6. 次 CTA：`查看源码`（GitCode）
7. 数据：版本号、发布日期、体积、平台、免费声明（均来自可核对文件）
8. 状态：图片 Error 降级（见 03-states.md）
9. 交互：Hero 图 hover lift（仅精确指针）
10. 可访问性：图片 alt 描述界面内容；徽标为 figcaption
11. 验收：首屏无横向溢出、图片 5/5 加载、无 console error
12. 备注：徽标文字明确写出「由当前构建 v0.5.6 实际运行截取」

### P2 · 为什么（`data-pid="p2-why"`）
1. 锚点：`#why`；2. 主任务：信任判断；3. 主视觉：一块白面板 + 两道发丝线
4. 组件：编号 01/02/03 + 标题 + 说明 + 补充细节
5. CTA：无（保持克制，避免打断阅读）
6. 数据：「三个不」全部来自 README / PRD / 设置面板文案
7. 状态：纯静态
8. 交互：无
9. 可访问性：语义化标题层级 h2 → h3
10. 验收：三行等宽、发丝线只在行间出现
11. 备注：不使用彩色左边框、不给每行配图标
12. 取舍：放弃「四个特性卡片」方案，避免碎片化

### P3 · 界面（`data-pid="p3-views"`）
1. 锚点：`#views`；2. 主任务：切换视图确认功能
3. 主视觉：四张真实截图叠放，同一容器内 crossfade
4. 组件：segmented pill（4 档）+ 滑块 + 图注 + 演示数据声明
5. CTA：无
6. 数据：四张图来自 `_workflow/capture-screens.cjs` 从当前 dist 采集
7. 状态：Initial / 切换中 / Success / 图片 Error
8. 交互：点击 + 左右方向键；滑块 transform 位移，transition 可中断
9. 可访问性：`role="tablist"` / `aria-selected` / `aria-controls` / `aria-live`
10. 验收：点击「趋势」后 `data-active` 与 active 图片下标一致（已实测 1/1）
11. 备注：图注随切换更新
12. 取舍：放弃四张图并排，避免首屏过载

### P4 · 隐私（`data-pid="p4-privacy"`）
1. 锚点：`#privacy`；2. 主任务：核对记录边界
3. 主视觉：单一白面板内两列对照
4. 组件：两列列表 + 脚注
5. CTA：无
6. 数据：来自 README「它记录什么」表与「不记录的」原句
7. 状态：纯静态
8. 交互：无
9. 可访问性：列表语义 `<ul>/<li>`
10. 验收：680px 以下两列折叠为一列
11. 备注：「窗口标题默认不记录」在两处重复强调
12. 取舍：不用红/绿语义色，仅用发丝线与灰点，保持单强调色

### P5 · 下载（`data-pid="p5-download"`）
1. 锚点：`#download`；2. 主任务：转化
3. 主视觉：`--grad-cta` 彩色区块 + 两枚模糊光晕
4. 组件：kicker / H2 / 说明 / 三个 glass-chip / 诚实提示
5. CTA：仅一个 setup 按钮，走发行版直链（302 已核实）；顶部导航与首屏两处入口同链
6. 数据：文件名来自发布仓目录实查
7. 状态：纯静态 + 外链
8. 交互：press 反馈（120ms）
9. 可访问性：外链 `target="_blank"` + `rel="noopener noreferrer"`
10. 验收：三处下载入口 href 完全一致且直链 302 有效
11. 备注：主动写明未签名 / SmartScreen / WebView2 / 退出托盘再安装
12. 取舍：只保留一个 setup 入口，减少选择成本；实查 404 的两种产物只在提示文案里给目录
