# 03 · 状态矩阵（S1 / G2）

**口径说明**：这是纯静态营销页，没有业务接口、表单或登录，因此 Loading / Empty 指的是**资源态与交互态**，不是业务数据态。下表不虚构「接口报错」这类本页不存在的情况；但 Error 一栏必须有可执行的下一步，且已在 `index.html` 中真实实现。

| 区段 | Initial | Loading | Empty | Error（含下一步） | Success |
|---|---|---|---|---|---|
| P1 首页 | 首屏渲染，Hero 图占位尺寸已由 `width/height` + `aspect-ratio` 锁定 | 图片解码中，`<img>` 未 complete | 不适用（无列表数据）；若截图资源缺失则见 Error | 图片 onerror → 父容器 `.img-error`，显示「界面预览未能加载」+「到发布仓查看版本说明」链接 | 图片 5/5 加载，徽标可见，无 console error |
| P2 为什么 | 三行文案 + 两条发丝线直接可见 | 无 | 不适用（内容静态写入） | 不适用；无异步资源 | 面板完整、行间无多余边框 |
| P3 界面 | 默认「今天」视图，滑块在第 0 档 | 点击后 280ms 内图片 crossfade + 滑块位移（transition 可中断） | 不适用；四个视图恒有内容 | 任一截图 onerror → `.screen-stage.img-error`，显示提示 + 发布仓链接；切换逻辑仍可用 | `data-active`、active 图片下标、`aria-selected`、图注四者一致（实测 1/1） |
| P4 隐私 | 两列对照可见 | 无 | 不适用 | 不适用 | 680px 以下折叠为单列 |
| P5 下载 | 彩色 CTA + 一个玻璃按钮（另两处入口同链） | 外部下载由浏览器负责（不在本页 Loading 范围） | 不适用 | 离线时链接无法打开：本页不拦截，属已知限制，见 HANDOFF 第 9 节 | 三处入口均触发 setup.exe 下载（302 已核实） |
| 全局 | 导航在顶部时无下边框 | 滚动 > 8px 时 hairline 与浅阴影以 280ms 渐入 | 不适用 | JS 未加载时导航与所有内容仍可读（无 JS 依赖的内容） | 1366 / 1440 / 1920 三档无横向溢出 |

## 已在实现中落地的 Error 处理
- `img[data-img]` 统一绑定 `error` 事件，给最近的 `.hero-art` / `.screen-stage` 加 `.img-error`。
- 两个降级面板都带一条可点击的下一步（发布仓 / 版本说明页），不是单纯的「加载失败」死文案。
- 降级面板用 `role="status"`，读屏可感知。

## 未覆盖（诚实登记）
- 外链（Gitee / GitCode）不可达时，本页没有探测与提示，交给浏览器处理。
- 无表单，故不存在校验错误态、提交中态、成功回执态。
